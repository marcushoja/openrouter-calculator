Bitte lade eine JSON-Datei hoch, um das Dashboard zu füllen.

Nutze den Standard-JSON-Export in DBeaver. Dieses Dashboard ist speziell für die opencode Datenbank konfiguriert. Führe dazu folgendes SQL aus: 

SELECT 
    id AS session_id,
    title,
    time_created AS created,
    time_updated AS last_access,
    model,
    (tokens_input + tokens_cache_write) AS frontend_input_tokens,
    (tokens_output + tokens_reasoning) AS frontend_output_tokens,
    tokens_cache_read AS frontend_cached_tokens
FROM session
WHERE tokens_input > 0 OR tokens_output > 0
ORDER BY created DESC;

Wichtiger Hinweis: Falls der Zugriff in DBeaver verweigert wird (Datenbank ist gelockt, weil OpenCode gerade im Hintergrund läuft), erstelle am besten kurz eine lokale Kopie der Datenbankdatei und verbinde dich mit dieser Kopie.

Speicherort der Datenbank: Standardmäßig findest du die Datei hier:
  • Windows: %APPDATA%\opencode\opencode.db (oder %LOCALAPPDATA%)
  • WSL / Linux: ~/.config/opencode/opencode.db (oder ~/.local/share/)
